# MMViewerの検証

依頼された変更が使える状態まで確認する。リポジトリの `AGENTS.md` とユーザーの依頼範囲に従い、今回必要な参照だけを読む。

| 今回の作業 | 参照 |
| --- | --- |
| C++のビルド、回帰テスト、配布exeの更新、Mermaid資産の変更 | [ビルドとテスト](references/build-and-test.md) |
| GUI起動、既存画面へのファイル転送、画面消失、ハング | [起動と障害調査](references/runtime.md) |

文章だけの修正やソースを読むだけの評価には、このスキルのビルド・起動手順を適用しない。通常の変更確認を、耐久試験や依存ライブラリの更新へ自動的に広げない。

修正依頼に必要なローカル検証と、そこで見つかった変更由来の不具合修正は続けて行う。判断待ちが必要な部分があっても、独立して進められる確認を完了する。

成果の説明では、ビルド成功、実行したテスト、`dist` への配置、GUIでの操作確認を区別する。未実行の段階を完了扱いにしない。
